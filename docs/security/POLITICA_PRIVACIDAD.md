# Política de Privacidad y Tratamiento de Datos Personales
**MiLocal - Versión 1.0 (Chile)**

## 1. Introducción
MiLocal se compromete a proteger la privacidad de sus usuarios de acuerdo con la **Ley N° 19.628** sobre Protección de la Vida Privada y los estándares de la **ISO 27001**.

## 2. Datos Recolectados en el Onboarding
Para el funcionamiento del motor de matchmaking, recolectamos:
- Datos Identificatorios (Nombre, RUT, Email).
- Datos Financieros (Carpeta Tributaria del Sii, Comportamiento en burós de crédito).
- Datos de Negocio (Rubro, proyecciones de venta, historial de locales anteriores).

## 3. Finalidad del Tratamiento
Los datos se utilizan exclusivamente para:
1. Generar un **Score de Confianza** para el arrendador.
2. Facilitar el "Match" basado en compatibilidad de rubro y capacidad de pago.
3. Análisis estadístico anonimizado para tendencias de mercado.

## 4. Consentimiento Informado
Al utilizar el módulo de Assessment, el usuario otorga consentimiento **explícito e irrevocable** (mientras mantenga la cuenta activa) para que MiLocal consulte fuentes de datos externas confiables para validar sus antecedentes comerciales.

## 5. Derechos ARCO (Acceso, Rectificación, Cancelación y Oposición)
Cualquier usuario puede solicitar el acceso o la eliminación de sus datos enviando un correo a `privacidad@milocal.cl`. La eliminación de datos financieros implicará la pérdida de los "Badges" de verificación y posibles matches activos.

## 6. Seguridad
Aplicamos controles técnicos de vanguardia:
- Tokenización de datos sensibles.
- Auditorías de acceso semestrales.
- Anonimización de datos para procesos de machine learning.
