## 3. Plan de Gestión de Cambios (Change Management)
- **Cambios Estándar:** Actualización de estilos CSS, textos menores. (Pre-aprobados).
- **Cambios Normales:** Nuevas funcionalidades de scoring, migración de BD. (Requieren revisión en el CAB - Change Advisory Board ágil).
- **Cambios de Emergencia:** Parches de seguridad críticos. (Despliegue inmediato + revisión retrospectiva).

## 4. Gestión de Incidentes
- **Nivel 1:** Soporte automatizado (Chatbot MiLocal).
- **Nivel 2:** Soporte técnico (Analista de QA).
- **Nivel 3:** Ingeniería (Desarrolladores Core).
